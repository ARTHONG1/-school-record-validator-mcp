# 한계와 해석 기준

## 판정 범위

- v1은 `kr-moe-school-record-elementary-2026.1` 규칙팩을 사용하는 2026학년도 초등학교 전용입니다. 중학교와 고등학교 문서는 활성 말뭉치, 검색, 판정에 섞이지 않습니다.
- 문구 탐지는 사실관계, 실제 작성자, 교사의 직접 관찰 여부를 텍스트만으로 증명할 수 없습니다. 작성 경위와 활동 주체가 필요한 규칙은 입력 metadata를 함께 판단합니다.
- 특정 기관명이나 활동 주체처럼 문맥에 따라 허용 여부가 달라지는 항목은 충분한 context metadata가 없으면 `review`로 반환합니다.
- 상위·하위 공식 근거의 충돌이 범위나 예외로 해소되지 않으면 두 자동 판정을 억제하고 `SOURCE-RULE-CONFLICT` review finding을 반환합니다.

## 결과 해석

- `pass`는 현재 규칙팩에서 탐지된 항목이 없다는 의미입니다. 교육부의 공식 승인, 학교 내부 결재, 법률 자문을 대신하지 않습니다.
- `official-policy`는 교육부 공식 문서를 근거로 한 규칙입니다.
- `editorial-caution`은 문장 품질을 위한 로컬 편집 경고이며 교육부 금지 규정이 아닙니다. `official_plus_editorial` 프로필에서만 활성화됩니다.
- 검색 결과와 인용은 판단 근거 확인을 돕지만, 학교 담당자는 적용 시점의 최신 훈령과 기재요령을 최종 확인해야 합니다.

## 길이와 시스템 범위

- 고정 한도는 성명 60Byte, 주소 900Byte, 학적 특기사항 1,500Byte, 출결 특기사항 1,500Byte, 봉사활동 실적별 활동내용 150Byte입니다.
- 창의적 체험활동, 일상생활 활동, 교과학습발달상황, 행동특성 및 종합의견에는 2026 초등 기재요령의 시스템 입력 범위에서 별도 고정 글자 수 제한을 임의로 적용하지 않습니다.
- 바이트 계산은 CRLF를 LF로 정규화한 UTF-8 기준입니다. 실제 입력 시스템의 추가 제약은 별도로 확인해야 합니다.

## 개정과 보안

- 공식 원본이 개정되어 SHA-256이 바뀌어도 기존 규칙팩을 자동 승격하거나 조용히 교체하지 않습니다. 새 버전으로 수집, diff 검토, 인용 재승인, 테스트를 거쳐야 합니다.
- 로컬 stdio 런타임은 학생 문안을 저장하거나 로그에 남기거나 네트워크로 보내지 않습니다. Remote MCP에서는 문안이 인터넷을 통해 운영 서버로 전송되지만 애플리케이션은 요청 본문을 저장하거나 로그에 쓰지 않습니다. MCP 호스트, Cloud Run 등 기반 플랫폼의 대화·접속 로그와 보관 정책은 이 서버가 통제하지 못하므로 별도로 검토해야 합니다.
- 원본 문서는 기본적으로 Git과 npm 배포물에서 제외됩니다. 재배포 권한을 확인하기 전에는 원본 스냅샷을 공개하지 않습니다.
