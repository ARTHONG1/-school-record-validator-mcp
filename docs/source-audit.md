## 훈령 본문 감사

직접 관찰 원칙의 기준 인용은 교육부훈령 제555호 제4조제2항의 다음 문장이다.

> ② 사용자는 학생에 대해 직접 관찰ㆍ평가한 내용을 근거로 자료를 입력해야 한다.

TXT와 HWPML 사본은 같은 현행 훈령 본문을 나타낸다. release corpus는 TXT에서 조ㆍ항 단위 청크를 만들고 HWPML은 문서 메타데이터와 교차검증 기록만 남긴다.

## 검증 및 릴리스 상태

공식 원본 통합 검사는 4/4 통과했다. 이 검사는 manifest 추출 하한, 고정 초등 PDF 페이지와 인쇄 쪽 좌표, 훈령 TXT-HWPML 교차검증, 별표 7~11의 주제 표식을 확인한다. 원본 파일 검증도 8/8 통과했고, 사람 검수 인용은 `data/evidence/verified-excerpts.json`에 Evidence ID 12개와 인용문 SHA-256으로 기록되어 있다.

corpus를 연속 두 번 생성한 결정성 검사와 봉인 번들 생성도 완료했다. 최종 릴리스 검증에서 단위·통합 테스트 160/160, 타입 검사, 빌드, stdio E2E 1/1, 무출력 대기 smoke test가 모두 통과했다.
